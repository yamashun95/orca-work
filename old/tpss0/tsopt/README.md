# TS最適化プロジェクト - MEA-CO₂-Water複合体

## プロジェクト概要

ORCA 6.1.1 を用いたMEA（モノエタノールアミン）-CO₂-水複合体の遷移状態（TS）最適化計算

## ファイル構成

### メインの計算結果

1. **スキャン計算結果**
   - `scan.013.xyz`: スキャンステップ13（エネルギーピーク）
   - 初期エネルギー: -399.088467 Hartree

2. **幾何最適化（単純Opt）**
   - `tsopt_simple_opt.xyz`: 最適化された構造
   - `tsopt_simple_opt.log`: 計算ログ
   - `tsopt_simple_opt.gbw`: ORCA 波動関数ファイル
   - 最適化後エネルギー: -399.088465 Hartree
   - 状態: **CONVERGED**

3. **周波数計算**
   - `tsopt_freq.log`: 周波数解析
   - 虚数周波数: -202.42 cm⁻¹ (TS的性質を示唆)

### 分析スクリプト

- `analyze_opt_structure.py`: 構造変化の詳細分析
- `tsopt_optimization_summary.md`: 計算要約

## 主要な知見

### エネルギー変化

| 段階 | エネルギー (Hartree) |
|------|-------------------|
| scan.013 初期値 | -399.088467 |
| 幾何最適化後 | -399.088465 |
| **差分** | **0.000002** |

### 構造変化

- **最大原子変位**: 0.001037 Å (微小)
- **平均原子変位**: 0.000462 Å
- **N-CO₂距離**: 2.0527 → 2.0523 Å (変化なし)

### 科学的意義

1. **scan.013 は最小値に非常に近い**
   - エネルギー変化が1e-6 Hartree 以下
   - 原子変位が1e-3 Å 以下

2. **虚数周波数の検出**
   - -202.42 cm⁻¹ は反応座標の虚数モードを示唆
   - TS特性の証拠

3. **TS最適化の困難さ**
   - OptTS + Hessian 計算でハング
   - RIJCOSX と解析的 Hessian の非相性

## 計算方法

### 使用論理

- **汎関数**: TPSS0 (ハイブリッド型)
- **基底関数**: def2-TZVP
- **溶媒効果**: CPCM/water
- **計算資源**: 16 MPI プロセス

### タイムライン

1. スキャン計算 → 20ステップ（scan.013がピーク）
2. スキャンピークの幾何最適化 → 1サイクルで収束
3. 周波数計算 → 虚数周波数を検出
4. OptTS試行 → XC微分計算でハング

## 今後の方向性

### 推奨される次のステップ

1. **より低いレベルでの OptTS**
   - GGA (BP86, PBE) での OptTS を試行
   - 計算時間短縮、ハング回避

2. **別のTS探索戦略**
   - IRC（内的反応座標）計算
   - Linear synchronous transit (LST)

3. **確認実験**
   - 異なる初期条件からの OptTS
   - アニーリング法による探索
